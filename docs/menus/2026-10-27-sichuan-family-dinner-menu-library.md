## 1. 分类口径

| 菜单分类 | 归类规则 |
| --- | --- |
| 荤菜 | 主料含肉、禽、水产或蛋的主菜，再按主蛋白质分组 |
| 素菜 | 主料不含肉、禽、水产和蛋的主菜 |
| 汤 | 作为可选汤品使用，再按主要蛋白质分组 |
| 待确认 | 仅凭菜名无法判断主料或做法的菜品 |
| 非推荐池 | 主食、小吃、甜品、水果和无法归入主菜角色的条目 |

分类说明：

- 不再沿用原图的“猪、牛、鸡、兔、水产、凉菜、素菜、大荤、半荤”等混合分类方式。
- 每道菜在主清单中只出现一次。荤菜按主蛋白质分组；含肉、禽、水产或蛋的菜不会放入素菜。
- 凉菜按实际主料归入荤菜或素菜，不单独占用一个菜单角色。
- 原图“大荤”和“半荤”为空，不保留为空分类。
- 只合并菜名完全相同的条目，相近菜名不强行合并。
